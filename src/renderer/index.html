Signature Verification

Enable real cryptographic signature verification for checkSig opcodes. When disabled, signature opcodes always return true (simulated mode).

Bitcoin Network

Select the Bitcoin network for signature verification and transaction validation.

Transaction Context

Provide transaction context for checkSig and checkMultiSig verification. checkDataSig does not require transaction context.

Note: checkSig/checkMultiSig require transaction context when signature verification is enabled. checkDataSig works with just message, signature, and public key on the stack.

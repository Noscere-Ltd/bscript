Settings

Signature Verification

Enable real cryptographic signature verification for checkSig opcodes. When disabled, signature opcodes always return true (simulated mode).

Verification

The Rúnar ScriptVM runs a script against a transaction of its own, so a script using checkPreimage can only pass there with that transaction's preimage on the stack. With this on, Verify substitutes it and hands the simulator the same digest, so both engines check the same thing. With it off, Verify says why it cannot compare such a script instead of comparing it anyway.

Transaction Version

Version 1 is the strict rule set: minimal number encoding and exactly one truthy item left on the stack. Version 2 and above relax both.

Bitcoin Network

The network Deploy broadcasts to and reads the balance from. A testnet WIF starts with c. It has no effect on running or verifying a script.

Transaction Context

Provide transaction context for checkSig and checkMultiSig verification.

AI Assistant

Configure an AI provider to generate, explain, and fix Bitcoin Scripts.

Note: checkSig/checkMultiSig require transaction context when signature verification is enabled.
